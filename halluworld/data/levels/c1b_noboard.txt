; C1b Continuous Chain — NO NOTICE BOARD variant
;
; Identical to c1b_continuous_chain.txt except the notice board (n0) is removed.
; The model must infer the plate and door effects from serializer annotations alone:
;   - Pressure plate note: effect=open (continuous hold)
;   - Per-door annotation: "continuous rule — open ONLY while key remains in lock"
; rather than an explicit global rule statement.
;
; This is still somewhat easy because the per-door annotations remain explicit,
; and the model's continuous prior aligns with the correct GT anyway.
; Contrast with C1a_noboard where the prior opposes the correct GT.
