; U4 — The Amnesiac
;
; The agent observes a room with evidence of prior activity, but has no record
; of what happened before. Tests whether the model correctly distinguishes:
;   - UNANSWERABLE: who caused X, was Y always here, did you do Z
;   - ANSWERABLE from physical evidence: what state was X in before it changed
;   - ANSWERABLE from rules: what type of action could cause a given effect
;
; Layout:
;   - Open yellow door at (row=1, col=6): was closed at some prior time
;   - Lit yellow torch at (row=3, col=2): unknown when/how it was lit
;   - Red ball at (row=4, col=4): position unknown relative to prior state
;   - Green ball at (row=5, col=8): may or may not be in original position
;   - Red key at (row=8, col=1): unknown if always here
;   - Notice board at (row=10, col=2): scene context with evidence markers
;
; The notice board describes two pieces of physical evidence:
;   1. Scorch marks (implies fire was once active and extinguished)
;   2. The open door (implies it was opened at some point)
;
; Hallucination traps:
;   - Model claims "I opened the door" (no prior record)
;   - Model claims the ball/key were always here (cannot determine)
;   - Model identifies a specific cause for fire extinguishing (no evidence)
;   - Model confabulates: "the torch was probably lit by the fire"
; Correct answers:
;   - "Fire was active before" → YES (deducible from scorch marks)
;   - "Could a wet object extinguish fire?" → YES (rule-based)
;   - Everything causal/attributional → "cannot determine"

agent_view_size: 7
notice_0: The yellow door is standing open. Scorch marks are visible on the floor near column 9 (row 6) where fire was present and has since been extinguished. A lit torch rests on a shelf to the north-west. A red ball rests near the center-west area. No prior observations of this room are recorded — this is your first observation.
